# Domain Terms

本章节定义了本系统的领域名词。

## Thoughtworks 认证中心
- 定义：由 Thoughtworks 内部维护的、用于**数字证书/荣誉等资质证明统一颁发的 API 服务**。
- 用法：接收证书信息，异步渲染带样式图片并返回图片地址，实现可信数字化证书发放。

## OpenAI API
- 定义：由 OpenAI 提供的**人工智能应用接口平台**，包括文本生成、文本嵌入、图片生成等能力。
- 典型用途：驱动聊天机器人、文档摘要、智能检索等。

## LangChain
- 定义：一个**用于构建大模型应用的 Python 框架**，支持文档解析、文本分割、检索增强、工作流编排等。
- 典型用法：RAG 流程、智能问答、文档助手、企业知识库。

## 培训课程（Training Course）
- 定义：针对特定岗位或能力提升，由组织内部或外部专家设计的系统化学习项目。
- 关键元素：课程名称、目标受众、学习目标、课程大纲、讲师、学习方式（线上/线下）、考核方式等。
- 场景：员工入职培训、技术赋能、业务流程培训、管理能力提升等。

## 完成时间（Completion Time）
- 定义：记录用户参与活动、完成培训或获得证书的具体日期和时间。
- 作用：便于追踪学习进度、统计参与情况，为资格审核和后续激励提供数据支撑。
- 通用格式：通常为 ISO 日期（如 2024-06-08），也可包含具体时分秒。

## 学员（Trainee / Learner）
- 定义：参与培训课程、学习活动并接受考核的个人。
- 常见信息：姓名、工号/学号、部门、岗位、个人邮箱。

## 培训讲师（Instructor / Lecturer）
- 定义：负责培训课程讲授、辅导及指导学员的专业人员。
- 资质：可为内部资深员工、外部行业专家或认证讲师。
- 职责：授课、答疑、布置作业与评分。

## 结营标准（Completion Criteria）
- 定义：学员被视为成功完成培训/课程所需满足的条件。
- 示例：达到规定的出勤率、通过考核测验、完成作业或实际项目等。

## 纪念证书（Certificate of Achievement）
- 定义：授予完成特定课程或项目并达到考核要求学员的官方证明文档。
- 内容：一般包括学员姓名、课程名称、完成时间、唯一编号、发证机构及签章。

## 培训项目编号（Training Program ID）
- 定义：唯一标识一次培训活动或课程批次的编号。
- 作用：便于系统追踪与管理，常用于后台数据统计、证书生成等。

## 课程反馈（Course Feedback）
- 定义：学员在完成课程后，对课程内容、讲师、组织等方面的评价和建议。
- 作用：提升课程质量和学员满意度，帮助后续改进优化。

## 业务开阐汇（Business Summary / Recap）
- 定义：对某次业务活动、培训、项目等做出的总结性陈述，覆盖核心成果、亮点与收获。
- 用途：向管理层、学员或相关方报告项目进展与价值体现，支持后期复盘和经验积累。

## OOCL AI Workshop 纪念证书
- 定义：Workshop 完成后，由 **Thoughtworks** 出具的电子证明。
- 目的：证明学习完成，不作为法律文书；通常含姓名、课程名、结营日期、唯一编号等**常见元素**（非规范字段）。
- 生成方法：需 **集成 Thoughtworks 认证中心的 API** 生成证书图片。
- 为何是 **Thoughtworks**：增强可信与统一出具。

# Techincal Terms

本章节定义了本系统相关和技术术词。

## 领域驱动设计（DDD, Domain-Driven Design）
- 定义：一种关注复杂业务领域建模和实现的软件开发方法论。
- 关键概念：包括**实体（Entity）**、**值对象（Value Object）**、**聚合（Aggregate）**、**限界上下文（Bounded Context）**、和**领域服务（Domain Service）**等。
- 目的：通过准确表达领域知识，降低软件复杂度，促进业务与技术的协同。

## Prompt Engineering（提示工程）
- 定义：人工为大模型（如 GPT）设计输入内容（Prompt），以获得更期待或更准确的响应。
- 关键手法：角色扮演、上下文补全、约束式表达、链式思维（Chain-of-Thought）等。
- 应用场景：AI 问答、总结、代码生成、复杂推理、多轮对话等。

## RAG（Retrieval-Augmented Generation, 检索增强生成）
- 定义：结合外部知识库检索与大模型生成能力的 AI 技术框架。
- 典型流程：用户问题 → 检索相关文档或片段 → 与问题拼接 → 输入大模型 → 生成类似**有依据的答案**。
- 优势：可利用**最新或专有数据**扩充模型知识，减少幻觉。

## Embedding（嵌入/向量化表示）
- 定义：将文本、图片或其他数据用高维向量数字化表示，便于相似度检索与机器理解。
- 应用场景：相似度搜索、语义检索、聚类、RAG。
- 常见模型：OpenAI embedding 系列，BERT，Sentence Transformers。

## FAISS
- 定义：Facebook AI 提出的**高效相似度搜索库**（Facebook AI Similarity Search），用于处理大规模向量数据（如 embedding）。
- 用法：支持高效的最近邻向量检索，可用于 RAG 向量数据库后端。

## Chunk（文本分块/切片）
- 定义：长文档以固定长度或自然段落进行拆分，每块称为 chunk。
- 意义：便于大型语言模型与向量库处理长文本，控制上下文长度，提升检索粒度。
